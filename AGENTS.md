# CydLan interface rules

- Treat the app as self-explanatory.
- Do not add user-facing instructions unless the user explicitly requests them.
- Do not add onboarding copy, helper paragraphs, usage directions, shortcut hints, explanatory subtitles, or promotional taglines to screens, empty states, dialogs, tooltips, or notifications unless explicitly requested.
- Keep concise control labels, accessible names, relevant status, and necessary error messages. State what happened without adding directions for using the app.
- Do not restore explanatory copy that the user has removed. Apply this rule to new features and revisions throughout the app.
